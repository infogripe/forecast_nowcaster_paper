# A Bayesian Framework for Forecasting Severe Acute Respiratory Infections (SARI) Hospitalizations Accounting for Reporting Delays

This repository contains the scripts used to run the forecasting models and conduct the analyses presented in the paper **"A Bayesian Framework for Forecasting Severe Acute Respiratory Infections (SARI) Hospitalizations Accounting for Reporting Delays."**

## Required package

The forecasting scripts require the **Nowcaster** R package.

Before running the scripts, please refer to the [Nowcaster package repository and documentation](https://covid19br.github.io/nowcaster/) for installation instructions and details on its functions.

## Repository structure

### `scripts/R_forecast/`

This folder contains the R scripts used to run the forecasting models evaluated in the paper.

| Script                                                                                | Description                                                              |
| ------------------------------------------------------------------------------------- | ------------------------------------------------------------------------ |
| [`epinow_paralelo.R`](scripts/R_forecast/epinow_paralelo.R)                           | Runs the EpiNow2 models in parallel.                                     |
| [`fct_forecast.R`](scripts/R_forecast/fct_forecast.R)                                 | Contains functions used by the forecasting scripts.                      |
| [`forecast_cut_3_weeks.R`](scripts/R_forecast/forecast_cut_3_weeks.R)                 | Runs the forecasting model after excluding the last three weeks of data. |
| [`forecast_mediana.R`](scripts/R_forecast/forecast_mediana.R)                         | Runs the median-corrected forecasting model.                             |
| [`forecast_no_delay_correction.R`](scripts/R_forecast/forecast_no_delay_correction.R) | Runs the forecasting model without correcting for reporting delays.      |
| [`forecasting_SRAG.R`](scripts/R_forecast/forecasting_SRAG.R)                         | Runs the Nowcaster forecasting model for SARI hospitalizations.          |
| [`nowcasting.summary.R`](scripts/R_forecast/nowcasting.summary.R)                     | Contains functions for summarizing the nowcasting results.               |

### `scripts/R_metrics/`

This folder contains the R scripts used to validate the forecasting and nowcasting results and calculate and summarize the performance metrics.

| Script                                                                                             | Description                                     |
| -------------------------------------------------------------------------------------------------- | ----------------------------------------------- |
| [`00_validation_forecasting_nowcaster.R`](scripts/R_metrics/00_validation_forecasting_nowcaster.R) | Validates the Nowcaster forecasting results.    |
| [`01_validation_nowcast.R`](scripts/R_metrics/01_validation_nowcast.R)                             | Validates the nowcasting results.               |
| [`02_metrics_summary.R`](scripts/R_metrics/02_metrics_summary.R)                                   | Summarizes the performance metrics.             |
| [`Tabela_metricas.R`](scripts/R_metrics/Tabela_metricas.R)                                         | Generates the performance metrics table.        |
| [`observed_data.R`](scripts/R_metrics/observed_data.R)                                             | Handles the observed data used in the analyses. |
| `.Rhistory`                                                                                        | R session history file.                         |

### `models/`

This folder contains the output files generated by the forecasting models.

### `epinowcast/`

This folder contains the output files generated by the EpiNow2 models.
